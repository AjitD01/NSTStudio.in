# NSTStudio.in

> **Story First.** Every powerful idea begins with a story. Transforming businesses into memorable brands.

An immersive Cartier-inspired 3D WebGL storytelling experience built for **Nikunj Storytelling Studio (NST)**.

---

## ✦ The Universes of Craft

- **01. Branding** — Identity systems, semiotic lore, and brand tokens that speak before you do.
- **02. Film** — Cinematic brand films, documentary narratives, and evocative stories.
- **03. Animation** — Kinetic 2D/3D character motion that breathes life into ideas.
- **04. Learning** — Masterclasses, design systems workshops, and visual storytelling pedagogy.

---

## ✦ Tech Stack & Architecture

- **Engine:** [React 19](https://react.dev/), [Vite](https://vitejs.dev/)
- **WebGL & 3D:** [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber), [@react-three/drei](https://github.com/pmndrs/drei)
- **Physics & Motion:** ScrollControls-driven camera rig, CatmullRom 3D spline ribbons, particle starfields, dynamic lighting
- **Typography:** Clash Display, Courier Prime, Satoshi
- **Testing:** Playwright Core with automated headless Chrome validation

---

## ✦ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
